An over-budget transfer is indistinguishable from a successful one

GhostKey clamps every ERC-7984 transfer against an encrypted budget. A request over budget is not rejected — it executes a real transfer carrying an encrypted zero. This is the measurement of whether that holds on chain.

180 live Sepolia transactions, 60 per path
1 distinct FHE operation sequence across all of them
1 distinct HCU value — 1,334,064 every time

χ² = 0.374 on 2 df against a critical 5.991 at p = 0.05. p = 0.83. The three distributions are not distinguishable.

The leak, bounded

mutual information, path ↔ gas    0.00151 bits per observation
Miller–Madow noise floor at N=180   0.00801 bits
cross-check  χ² / (2N ln2)          0.00150 bits

The measurement is a fifth of the floor — below what a perfectly independent process typically shows at this sample size, so the bias-corrected estimate is negative. Against 1.585 bits of outcome entropy, an observer learns nothing measurable.

80% power at n=180 detects       a spread of ±13 points (Cohen's w = 0.231)
the earlier run appeared to show a spread of ±12.5 points

The small run looked like a trend. This design is powered to detect precisely that effect and did not, which is a failure to find a real effect rather than a shrug. What it cannot rule out is a skew below ±13 points; seeing ±3 would need on the order of 3,000 samples.
